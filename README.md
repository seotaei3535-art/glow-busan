# GLOW BUSAN

부산 네일샵의 디자인·가격·예약 시간을 비교하는 가벼운 웹 앱입니다.

**공개 앱:** https://glow-busan.vercel.app/

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

http://127.0.0.1:3000 에 접속하세요. ES 모듈을 사용하므로 HTML을 파일로 직접 열지 마세요.

## 기능

- 부산 16개 구·군과 날짜·메뉴 선택 즉시 결과 갱신
- 지역별 3개씩 총 48개 테스트 후보, 시술 시간·영업시간·휴무·기존 예약 반영
- 찜, 최대 3곳 비교, 메뉴·연장·제거·아트 수별 가격·시간 계산
- 디자이너 선택, 참고 사진의 로컬 미리보기, 테스트 예약·취소·재예약
- 빈자리 알림 신청 내역, 시술 기록, 파트너 관리 화면
- 핑크·화이트 테마와 사용자 제공 튤립 이미지 URL, 모바일 지원

## 실제 연결 범위

Firebase `taeeui`의 Realtime Database `/glow/shops`에서 테스트 샵 6개를 읽고, 앱이 다른 지역의 테스트 후보를 보충합니다. SDK 대신 REST API로 공개 카탈로그만 읽어 추가 패키지가 필요 없습니다.

샵·리뷰·가격·가용 시간은 테스트 데이터입니다. 실제 영업점 또는 실시간 예약을 보장하지 않습니다. 예약·취소·가격 편집·시술 기록은 현재 브라우저에 저장되고 서버에 동기화되지 않습니다. 참고 사진은 전송하지 않습니다. 실제 결제·문자·빈자리 알림 발송·네이버 예약·Instagram DM은 미연결입니다.

파트너 로그인은 테스트 계정 `000-00-00000` / `1234`로 동작합니다. 브라우저 코드에 포함된 테스트 로그인은 실제 보안 인증이 아닙니다. 운영 전 Firebase 인증과 샵별 서버 권한 검사, 중복 예약 트랜잭션, 결제 검증을 구현해야 합니다.

## Vercel

현재 공개 앱은 Vercel Drop으로 직접 배포했습니다. 이 저장소와 자동 배포 연결은 별도 설정입니다. 저장소를 가져올 경우 Framework는 Other, Output Directory는 `public`, Build Command는 비워두세요. `vercel.json`에 정적 출력 설정을 포함했습니다.

## Firebase 규칙

`database.rules.json`은 이 앱 전용 최소 예시입니다. **기존 taeeui 프로젝트는 다른 앱도 사용하므로 전체 규칙을 이 파일로 덮어쓰지 마세요.** 기존 콘솔 규칙에 `glow.shops` 경로만 병합해야 합니다. 현재 원격 규칙은 기존 경로를 보존하고 공개 샵 읽기만 허용하며 클라이언트 쓰기를 차단했습니다.

`firestore.rules`와 `storage.rules`는 기본 차단 예시이며 현재 앱은 Firestore·Storage를 사용하지 않습니다. 공개 웹 설정은 관리자 비밀키가 아닙니다. `.env`, 서비스 계정 키, 실제 비밀번호와 고객정보는 커밋하지 마세요.

## 테스트

```sh
npm test
```

가격 계산, 시간 겹침, 휴무·지원 메뉴·과거 시간 처리, 16개 구·군 후보 수, Firebase 데이터 검증을 테스트합니다.

## 파일

- `public/`: 배포되는 웹 화면과 로직
- `tests/`: Node.js 기본 테스트
- `server.mjs`: 로컬 정적 서버
- `vercel.json`: Vercel 정적 배포 설정
- `firebase.json`, `.firebaserc`, `*.rules*`: Firebase 설정과 규칙 예시
